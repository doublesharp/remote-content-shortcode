# Reporting a vulnerability

Report suspected vulnerabilities privately through [GitHub's Report a vulnerability form](https://github.com/doublesharp/remote-content-shortcode/security/advisories/new).

Include:

- The plugin version and relevant WordPress/PHP versions.
- The affected shortcode, block, or administrator operation.
- Reproduction steps and a minimal proof of concept using test data.
- The required permissions and expected impact.

Do not include live passwords, tokens, customer data, or confidential endpoint responses. Keep exploit details out of public issues while the report is being assessed. General bugs without sensitive security details can use [GitHub Issues](https://github.com/doublesharp/remote-content-shortcode/issues).

Security fixes are maintained in the latest plugin release. Version 1.5 and earlier are affected by CVE-2023-45652, CVE-2024-2089, and CVE-2024-2090. Version 2.0 addresses those reports; check the release and WordPress.org availability before upgrading.

For the plugin's request, credential, output, and resource restrictions, see [Security and compatibility](docs/security.md).
